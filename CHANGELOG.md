# Changelog

## 0.1.0

Initial CLI release.

- Added `devvault init` for starter local setup.
- Added `devvault sync` for fetching GitHub PR snapshots.
- Added `devvault status` for PR lifecycle grouping and next actions.
- Added `devvault generate` for contribution, changelog, resume, and website Markdown output.
- Added `devvault prompt` for agent handoff prompts.
- Added local JSON storage, contribution ledger merging, GitHub check/review enrichment, tests, and CI.
